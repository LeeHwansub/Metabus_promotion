## 2. 전체 연출 및 디자인 방향
| 요소 | 방향 |
|---|---|
| 현실 공간 | 차분하고 어두운 톤, 낮은 채도의 색감 |
| 전환 효과 | 스마트폰 빛, 공간의 변화, 자연스러운 디졸브 |
| 버스 | 세련된 미래형 셔틀, 세계를 연결하는 상징 |
| 가상 세계 | 따뜻한 자연광, 풍부한 색감, 판타지 분위기 |
| 캐릭터 | 현실 인물과 연결되는 개성 있는 3D 아바타 |
| 카메라 | 시네마틱한 클로즈업과 부드러운 트래킹 |
| 음악 | 초반 잔잔하고 차분하게, 세계 진입 시 점진적으로 확장 |
| 효과음 | 스마트폰 알림음은 시작과 엔딩에서 동일하게 사용 |

## 3. 색감 전환 (핵심)
현실은 차갑고 무거운 느낌에서 시작 → 새로운 세계로 진입할수록 따뜻하고 생동감 있는 색으로 전환.

| 구간 | 색감 |
|---|---|
| SCENE 01 현실 (00–07초) | 차갑고 무거운 저채도, 어두운 톤 |
| SCENE 02 초대 (07–10초) | 어두운 현실 속 스마트폰의 은은하고 따뜻한 빛 |
| SCENE 03 이동 (10–14초) | 빛이 공간으로 퍼지며 점진적으로 따뜻해짐 |
| SCENE 04 변화 (14–19초) | 따뜻한 빛이 인물을 감싸며 채도 상승 |
| SCENE 05 경험 (19–25초) | 따뜻한 자연광, 풍부하고 생동감 있는 색 |
| SCENE 06 재초대 (25–30초) | 따뜻한 빛이 서서히 사라지며 종료 |

## 9. 제작 시 주의할 점
1. **캐릭터 일관성:** 학생·직장인의 현실 모습과 변신 후 아바타의 연결성 유지
2. **버스 디자인 일관성:** 모든 장면에서 동일한 버스 디자인
3. **알림 UI 일관성:** 시작과 엔딩의 알림 문구·디자인 동일
4. **콘텐츠 다양성:** 숲·자연만 강조하지 않고 게임, 탐험, 소셜 경험을 함께
5. **실제 서비스와의 연결:** 실제 METABUS 사이트 화면은 AI 생성 대신 캡처/녹화 삽입
6. **세로형 대응:** 인물과 주요 오브젝트는 중앙 안전 영역에 배치
